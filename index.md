# Racing Shadow Data Bridge

Racing Shadow Data Bridge is a private, non-commercial horse-racing research application. It uses owner-authorised, read-only Gmail access to retrieve daily racecard emails and may use Google Sheets to store private research results.

The application does not place bets, send emails, or process payments.
